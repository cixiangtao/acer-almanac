# Support

English | [简体中文](SUPPORT.zh-CN.md)

Start with the [README](README.md), [core package documentation](packages/core/README.md), and existing [GitHub Issues](https://github.com/cixiangtao/acer-almanac/issues).

When opening an issue, include the affected surface, package or extension version, Node.js or browser version, operating system, minimal reproduction, expected behavior, actual behavior, and relevant error output. Remove credentials and personal data.

Use the private channel in [Security](SECURITY.md) for vulnerabilities. Feature requests are welcome, but the project does not promise a fixed support scope, response time, or implementation schedule.
