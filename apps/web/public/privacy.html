Acer 老黄历隐私政策

生效日期：2026 年 7 月 23 日

Acer 老黄历是一款离线优先的 Chrome 扩展，用于在工具栏弹窗中展示公历、农历、每日宜忌和 基于用户生日计算的运势。

处理的数据

扩展仅处理用户主动输入的生日。生日可能属于个人信息，但它只用于在用户设备本地计算和展示 生日运势。

数据存储

生日通过 chrome.storage.local 保存在用户设备本地，以便下次打开扩展时恢复。扩展不会将生日或其他用户数据发送到开发者服务器 或任何第三方。

数据共享与使用

  • 不出售、共享或传输用户数据。
  • 不将用户数据用于广告、信用评估或与核心功能无关的用途。
  • 不收集浏览记录、网站内容、位置、身份验证信息或使用分析数据。
  • 不加载或执行远程代码。

权限说明

扩展仅申请 storage 权限，用于保存用户主动输入的生日。该权限不用于读取网页内容 或跟踪浏览活动。

用户控制

用户可以随时在扩展中修改生日。卸载扩展会删除由扩展保存在 Chrome 本地存储中的数据。

有限使用

本扩展对 Chrome API 所获取信息的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。

政策变更

如果扩展的数据处理方式发生变化，本页面会同步更新，并标注新的生效日期。

联系我们

如对本隐私政策有疑问，请通过 GitHub Issues 联系。
